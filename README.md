# ✈️ Desktop-приложение «Инспектор аэропортов»

## Описание проекта
Кроссплатформенное десктопное приложение для анализа загруженности аэропортов и мониторинга расписания рейсов. Приложение предоставляет удобный интерфейс для взаимодействия с базой данных авиаперевозок, позволяя пользователям получать детальную информацию о вылетах и прилетах, а также визуализировать аналитику пассажиропотока с помощью интерактивных графиков.

---

## 🛠 Стек технологий
- **Язык программирования:** C++ (стандарт C++17)
- **Фреймворк:** Qt 6 (Core, Widgets, Sql, Charts)
- **База данных:** PostgreSQL v15
- **Система сборки:** CMake
- **Архитектура и паттерны:** MVP-подход для начальной версии, Signal-Slot концепция Qt

---

## 🚀 Реализованный функционал и технические решения

### 1. Интеграция с базой данных и отказоустойчивость
- **Подключение к PostgreSQL:** Настроено защищенное подключение к удаленной БД с использованием модуля `QtSql` (`QPSQL`).
- **Автоматическое восстановление соединения:** Реализован механизм отказоустойчивости (Keep-Alive). В случае обрыва связи или неудачной попытки подключения при старте, запускается асинхронный таймер (`QTimer`), который каждые 5 секунд пытается восстановить соединение.
- **Индикация статуса:** Пользователь всегда видит текущее состояние подключения в нижней панели (цветовая индикация: зеленый/красный текст). Элементы управления автоматически блокируются до успешной загрузки словарей (списка аэропортов).

### 2. Пользовательский интерфейс (UI/UX)
- **Проектирование форм:** Интерфейс спроектирован в Qt Designer (файлы `.ui`) с использованием динамической компоновки (`QVBoxLayout`, `QHBoxLayout`), что обеспечивает корректное масштабирование окон при изменении их размера.
- **Управление потоком данных:**
  - Реализована фильтрация данных с использованием радиокнопок (Вылет/Прилет), объединенных в `QButtonGroup` для обеспечения строгой логики исключающего выбора.
  - Внедрена валидация ввода: календарь (`QDateEdit`) аппаратно ограничен диапазоном дат, присутствующих в БД (15.08.2016 – 14.09.2017), что исключает возможность формирования заведомо пустых SQL-запросов.
- **Отображение табличных данных:** Расписание рейсов выводится через `QTableView` с привязкой к `QSqlQueryModel`. Настроено автоматическое растягивание столбцов по содержимому и ширине окна (`ResizeToContents`, `StretchLastSection`).

### 3. Модуль аналитики и визуализации данных
- **Обработка данных на стороне СУБД:** Написаны оптимизированные SQL-запросы с использованием функций агрегации (`COUNT`) и группировки по периодам (`date_trunc('month', ...)`, `date_trunc('day', ...)`).
- **Построение графиков (Qt Charts):** Модальное окно статистики разделено на две вкладки (`QTabWidget`):
  - **Годовая статистика:** Реализована через `QBarSeries` и `QBarCategoryAxis`. Данные выводятся в виде столбчатой диаграммы с распределением нагрузки по месяцам.
  - **Месячная статистика:** Реализована через `QLineSeries` (линейный график).
- **Решение сложных краевых задач при отрисовке:**
  - Внедрена динамическая настройка осей координат (динамический расчет Max и Min для оси Y).
  - Решена проблема схлопывания графика при отсутствии данных (задан дефолтный диапазон, исключающий деление на ноль в ядре Qt).
  - Включено отображение точек на графике (`setPointsVisible(true)`) для корректной визуализации месяцев, где рейсы осуществлялись лишь в единичные дни.
  - Реализована строгая привязка фильтрации к конкретному году и месяцу, чтобы предотвратить наложение данных из разных лет друг на друга.

### 4. Кроссплатформенность и деплой
- Скрипт сборки `CMakeLists.txt` настроен для компиляции приложения под Windows, Linux и macOS.
- Использованы системные макросы `WIN32` и `MACOSX_BUNDLE`.
- Интегрирована команда `qt_generate_deploy_app_script`, которая автоматически подтягивает необходимые динамические библиотеки (DLL или `.so`) при упаковке релиза, что позволяет запускать приложение на машинах конечных пользователей без установленного Qt.
